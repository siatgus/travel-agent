# 合规申报材料包（使用说明）

本目录下的三份材料对应「大模型登记 + 安全评估」两道申报流程的必交文件，
全部从项目实际代码实现中整理而成——每一处机制描述都对应可演示、可核查的
代码行为，审核方要求现场演示时可直接对应到具体模块。

## 文件清单

| 文件 | 对应申报流程 | 说明 |
|---|---|---|
| `01-内容安全管理制度.md` | 大模型登记 + 安全评估 共用 | 制度文本，含拦截词库管理、处置流程、日志留存 |
| `02-安全评估自评估报告.md` | 安全评估（公安网安） | 按规定的七大内容逐项展开 |
| `03-大模型登记-调用情况说明.md` | 大模型登记（属地网信办） | 调用已备案模型的说明 + 二次处理立场声明 |
| `04-评估测试题集.md` | 大模型登记（属地网信办） | 拦截测试 + 放行测试 + 功能评估三类用例 |
| `05-拦截关键词库.csv` | 大模型登记（属地网信办） | 当前生效的全部内置词，可直接导入电子表格 |

## 提交前必须完成的填写项（搜索「【待填写」）

- 公司全称、统一社会信用代码、注册地址
- 安全管理负责人姓名、职务、联系方式（须能接监管电话回访）
- 产品名称（注意：代码中同时出现过「行野」「晴航旅行助手」两个叫法，
  提交前必须统一为最终注册名称，协议页面同步修改）
- 域名、ICP 备案号（ICP 下发后回填）
- 投诉举报渠道（邮箱 / 电话，必须真实可达，监管会抽查拨打）
- 测试环境地址与测试账号（登记材料要求提供可登录的测试通道）

## 转正式格式

Markdown 仅作为编写与版本管理载体。提交流程要求打印签字盖章的 PDF：

1. 全文搜索替换【待填写】项；
2. 粘贴进 Word 模板（标题黑体三号、正文仿宋 GB2312 四号、行距 28 磅）；
3. 导出 PDF，骑缝章 + 尾页盖章签字，扫描件上传申报平台。

## 与代码的对应关系（审核员问起时的回答口径）

| 材料中的机制 | 代码位置 |
|---|---|
| 内容安全双审 | `src/travel_agent/moderation.py`（scan / sanitize_output） |
| 拦截记录落库与复查 | `moderation.log()` → SQLite moderation_log 表，管理后台「内容审计」 |
| 审计日志留存 180 天 | `src/travel_agent/auditlog.py`，`data/logs/audit-*.jsonl`，`/api/health` 可自检 |
| 用户真实身份核验 | `src/travel_agent/auth.py`（手机验证码登录） |
| 限流风控 | `src/travel_agent/ratelimit.py`（令牌桶，user+ip 双维度） |
| 生成内容显式标识 | `src/travel_agent/render_html.py` 页脚 `.aigc-mark`；聊天页 `#aigc-tip` |
| 数据最小化与注销删除 | `server.py` 隐私政策页 + `conversations.py` 删除接口 |
