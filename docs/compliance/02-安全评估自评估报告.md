## 一、服务基本情况

### （一）服务概述

本服务是一个面向公众的旅行规划智能助手，用户通过自然语言对话提出旅行需求（目的地、日期、人数、预算、偏好等），服务生成结构化行程方案（含每日景点安排、餐饮推荐、交通衔接、预算明细）并渲染为可视化行程页。服务形态为网站（PC/移动端浏览器访问）。

### （二）技术实现方式

1. **生成能力来源**：本服务**不自主研发、不训练、不微调任何大模型**，通过 API 接口调用已通过国家网信办备案的大模型服务（DeepSeek，备案号【待填写：查询补充】），属于调用已备案模型提供生成式人工智能服务的应用；
2. **内容安全**：采用输入侧与输出侧双向内容审核（详见本报告第三部分）；
3. **信息源**：行程数据来源为公开地图服务、气象服务及公开网络信息，全部在境内获取。

### （三）用户规模与服务范围

服务上线初期预计注册用户【待填写：预估规模】，日活跃用户【待填写】。服务仅面向中国境内用户提供，全部数据存储于境内服务器（服务商：【待填写：阿里云/腾讯云等，地域：境内】）。

### （四）舆论属性或社会动员能力分析

本服务的功能边界：根据用户输入生成旅行建议文本。用户之间无内容发布、转发、评论、点赞等社交功能；生成内容仅在用户本人会话内呈现。用户可选择将行程页生成分享链接供他人查看，分享页为**只读静态页面**，不含互动功能，且保留人工智能生成内容标识。

**自评结论**：本服务属于「利用生成式人工智能技术向公众提供文本生成服务」的情形，按规定履行安全评估义务；同时通过功能设计（无社交互动、分享页只读带标识）主动控制舆论属性风险。

## 三、用户真实身份核验机制

1. **核验方式**：用户须以中国大陆手机号接收短信验证码完成登录，首次登录自动注册；系统不留存验证码明文（验证码短时效存储、用后即失效）；
2. **防滥用核验**：验证码发送与登录按「手机号 + IP」双维度限流，防范短信轰炸、批量注册；
3. **实名信息展示**：手机号全库脱敏展示（中间四位掩码），仅用于账号识别与核验记录；
4. **核验记录**：每次登录（含时间、结果、用户标识）均写入审计日志，留存不少于六个月。

## 四、日志留存机制

### （一）留存内容与期限（均不少于六个月）

| 类型 | 记录内容 |
|---|---|
| 登录日志 | 登录时间、用户标识、登录结果、新注册标记 |
| 服务调用日志 | 生成服务调用时间、用户标识、会话标识、响应耗时、产出形态、输入输出内容摘要 |
| 内容安全日志 | 拦截方向、命中类别、命中词、内容摘要、处置动作 |
| 限流日志 | 触发限流的用户/IP、所属限流桶、等待时长 |

### （二）技术保障

审计日志按天分文件存储（JSON Lines 格式），留存周期配置为 180 天，超期自动清理；日志系统具备自检接口可随时核查运行状态；日志写入采用追加模式且失败不影响业务、留有失败计数。

### （三）依法配合

可按法定程序向属地网信部门、公安机关提供指定时段日志数据的检索与导出。

## 五、违法有害信息防范处置机制

### （一）防范措施（输入侧 + 输出侧双审）

1. **输入侧**：用户消息进入模型前经本地关键词库审查（七类种子词 + 运营扩充词库，支持热更新，具备全角半角、字符插入等变体规避识别能力），命中即拒答，违法有害信息不进入生成环节；
2. **输出侧**：模型生成结果呈现前再次审查。政治、暴力、色情三类高危命中整条替换为兜底话术；其余类别命中词就地打码；
3. **词库维护**：内容审核岗每周检查更新，监管通报 24 小时内回补；词库扩充遵循低误伤原则；
4. **人工复查**：全部拦截记录进入管理后台复查模块，支持误报标记与回补闭环。

### （二）处置动作与记录

处置分为输入拒答、输出硬阻断、输出打码、限流四级，全部处置动作记录入库（含时间、类别、命中词、摘要、用户与会话标识），留存不少于六个月。

### （三）生成内容标识

聊天界面常驻「由人工智能生成合成，仅供参考」提示；行程页页脚显著标注人工智能生成标识。分享出去的行程页同样保留标识。

## 六、个人信息保护与防扩散

### （一）收集最小化

仅收集三类信息：手机号（登录核验）、用户主动发送的对话内容（服务必需）、服务运行技术记录（安全审计）。不收集通讯录、位置轨迹、相册等信息。

### （二）保护措施

1. 全站传输加密（HTTPS）；API 密钥等敏感配置加密存储；
2. 手机号在日志、后台展示、审计记录中一律脱敏；
3. 数据存储于境内服务器，不向境外传输用户个人信息；
4. 对话内容仅用于提供服务与安全审计，不用于广告画像，不出售给第三方。

### （三）防扩散

1. 用户历史行程仅本人登录可见，分享链接为只读静态页且保留 AI 标识；
2. 用户可随时删除历史对话；注销账号时全部信息永久删除；
3. 生成结果中的第三方数据仅含公开信息（景点、天气、路线），不涉及个人信息聚合。

## 八、为网信、公安部门提供技术数据支持的机制

1. **对接责任**：安全管理负责人为监管对接第一责任人，保证联系方式畅通；
2. **数据能力**：日志系统支持按时段、按用户、按事件类型检索导出；拦截记录与对话存档按会话关联，可完整还原事件链路；
3. **响应承诺**：收到依法查询要求后，1 个工作日内完成数据定位与导出，3 个工作日内完成内容汇报；
4. **主动报告**：发现重大违法有害信息传播等情形，立即向属地公安机关报告。
